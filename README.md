# EntraID_Automation_Suite
PowerShell scripts to automate Entra ID user lifecycle — bulk user creation, license assignment, Conditional Access, and inactive user management

🔐 Entra ID Automation Suite
📌 Problem It Solves
Manually creating users, assigning licenses, and configuring Conditional Access policies is time-consuming and error-prone at scale. This suite automates the entire identity lifecycle.

##
🛠️ Technologies Used
Microsoft Graph PowerShell SDK
Entra ID (Azure AD)
Conditional Access Policies
Microsoft 365 License Management
